# CapCut으로 만들기 (무료 기능만 사용)

완성본: `myoinositol_capcut_final.mp4` (9:16, 35초, 정보 자막 + 음성 자막 + 음성 + 배경음악).
아래는 같은 영상을 CapCut에서 더 좋은 음성으로 다시 만드는 방법입니다.

## 준비물 (이 폴더)
| 파일 | 용도 |
|---|---|
| `../01_front.mp4` ~ `../05_ending.mp4` | 자막 없는 장면 영상 |
| `subtitles.srt` | 자막 (시간 맞춤) |
| `narration_script.txt` | 음성으로 읽을 문장 8개 |
| `narration.wav` | 미리 만든 음성 (Supertonic 2 한국어 음성) |
| `bgm.wav` | 직접 합성한 배경음악 (저작권 걱정 없음) |

## 순서
1. **새 프로젝트 → 비율 9:16** 선택.
2. **미디어 가져오기**: `01_front` → `02_sticks` → `03_ingredients` → `04_haccp` → `05_ending` 순서로 타임라인에 놓기.
   길이를 30~35초로 맞추려면 각 클립을 약 6~7초로 늘리거나(속도 0.6~0.7배), 같은 클립을 한 번 더 써도 됩니다.
3. **자막**: 텍스트 → *로컬 자막 가져오기*에서 `subtitles.srt` 불러오기.
   (모바일 앱은 SRT 가져오기가 없을 수 있어요 → `narration_script.txt` 문장을 *텍스트 추가*로 붙여 넣기)
4. **음성(무료)**: 자막을 모두 선택 → *텍스트 읽기(텍스트 음성 변환)* → 한국어 여성/남성 음성 중 무료 표시된 것 선택 → *모든 자막에 적용*.
5. **배경음악(무료)**: 오디오 → 음악 → 검색창에 `vlog`, `bright`, `lofi`, `calm`, `상큼한` 등 입력 →
   **Pro(유료) 표시가 없는 곡**을 고르기. 또는 `bgm.wav`를 가져와 사용.
   배경음악 볼륨은 15~25 정도, 음성이 있는 구간은 *자동 볼륨 조절(덕킹)* 켜기.
6. **내보내기**: 1080p, 30fps.

## 주의
- CapCut 음악은 상업적(광고·협찬) 이용 허용 여부가 곡마다 다릅니다. 협찬 글이면 `bgm.wav`를 쓰는 게 안전합니다.
- 자막과 음성은 제품 상자에 적힌 내용만 사용했습니다 (효능 표현 없음).
