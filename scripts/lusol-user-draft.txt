서론: 요즘처럼 날씨가 쌀쌀해지거나 일교차가 커지는 시기에 자연스럽게 생각나는 음료 중 하나가 배도라지즙 / 오늘 소개할 제품은 루솔 진한 배도라지즙 비타플러스 / 일반적인 배도라지즙에 비타민 B2, B5, B6까지 더한 제품 / 주요 성분부터 섭취할 때 참고할 점, 구매 후기까지 하나씩 살펴볼게요 😊
1. 루솔 진한 배도라지즙 비타플러스, 어떤 제품일까? <배와 도라지를 함께 담고 비타민까지 더했다니, 구성이 궁금해지죠?>
 - 배와 도라지를 주원료로 만든 액상 음료 / 한 상자에 100ml씩 총 30개, 전체 3L / 개별 포장이라 챙기기 편리 / '비타플러스' = 비타민 B2, B5, B6 추가
 - 제품명 / 용량 100ml × 30개입 / 총용량 3L / 총열량 1,164kcal / 주요 원료 배, 도라지 / 추가 성분 비타민 B2, B5, B6
 - 상자의 HACCP(식품안전관리인증)과 CCM(소비자중심경영 인증) 표시
2. 핵심은 배 84%, 도라지 14.8%! <무엇이 얼마나 들어 있는지 알면 제품을 고르는 기준도 달라져요!>
 - 배 84% / 도라지 14.8% / 판토텐산칼슘 0.002% / 비타민B6염산염 0.0007% / 비타민B2 0.0005%
 - 배는 달콤하고 시원한 맛으로 음료에 많이 쓰이는 과일, 도라지는 특유의 향과 쌉싸름한 맛 → 배와 함께 맛의 균형
 - 원재료명 표시에 배(국산), 도라지(국산)로 원산지가 적혀 있음
 - 배도라지즙을 고를 때 이름만 보기보다 함량, 원산지까지 함께 살펴보기
3. 비타민 B2·B5·B6는 왜 들어 있을까? <배도라지즙에 비타민까지 더한 이유, 성분별로 알아볼까요?>
 - ① 비타민 B2(리보플라빈) ② 비타민 B5(판토텐산, 원재료명엔 판토텐산칼슘) ③ 비타민 B6(원재료명엔 비타민B6염산염) — 각각 1개입(100ml)당 함량과 기준치 비율로 소개
 - 비타민이 들어 있다고 이 음료를 비타민 보충용 건강기능식품으로 생각하면 안 됨 / 포장의 함량과 식품유형 확인 / 다른 영양제를 먹고 있다면 중복 여부도 살펴보기
4. 이런 분들이 관심을 가져볼 만해요! <온 가족이 함께 마실 음료를 찾고 있다면 구성부터 확인해 보세요!>
 - 배와 도라지가 들어간 음료를 찾는 분 / 일반 과일주스 외 다른 종류를 찾는 분 / 개별 포장으로 간편하게 챙길 제품을 선호하는 분 / 가족이 함께 마실 음료를 알아보는 분 / 비타민 B군이 추가된 제품의 원료 구성을 비교하고 싶은 분
 - 100ml씩 개별 포장이라 집에서나 외출할 때 준비하기 편리해 보임
 - 어린이에게 먹일 예정이라면 원재료와 알레르기 관련 표시를 먼저 확인 / 배도라지즙은 의약품이 아니라 음료라는 점 기억
5. 구매 후기와 섭취 전 확인할 점! <다른 사람들은 어떻게 느꼈을까? 구매 전 후기까지 체크해 봐요!>
 - (판매처 리뷰 퍼센트 대신) 네이버 블로그 후기 10개를 포인트별로 소개
